## Method checks that are in the tests
Churn labels equal a hand-written definition; features do not change when later data is added; avatars never appear in both
training and test; training labels end before the earliest test observation window; bootstrap intervals bracket the point estimate.

## Issues found and fixed during the real run
1. First design used only 4 cutoffs (1,113 training rows) and the forest could not beat the single feature "days since last seen". Now 24 cutoffs back to 2006 (9,645 training rows), validation over 4 periods, test over 3 periods.
2. A recency-only baseline was added so models must beat something meaningful.
3. Bootstrap intervals were added because the test set is small.

Issues found while running on real data
1. Xbox telemetry has no `genres` column; the genre comes from the metadata table. The loader requirement was wrong and was fixed.
2. `games.csv` and `reviews.csv` use backslash-escaped quotes and `\N` for missing; a plain read fails. Fixed with `escapechar`.
3. Missing values read as the text "N" after escaping, which hid release years of large games. Fixed.
4. Genre names differed between Xbox, Nintendo and IGDB ("Platform" vs "Platformer"), which split age trends across duplicates. Added a map.
5. Two guessed name aliases ("zelda", "mario kart") were removed because they could be several games.

# Tester pass (2026-10-28)
Attacked the finished project from several sides. Real bugs found and fixed (each has a regression test that fails on the old code):
1. Page 6 crashed whenever a genre was chosen: games with no genre data hold NaN and the genre parser called `.split` on it. Found by running the pages with random filter choices (64 of 80 random runs crashed).
2. Page 8 crashed (`KeyError 'shrunken_mean'`) when a filter left no genre with enough participants; the empty table had no columns.
3. The wording of the three frustration items was wrong in the page and docs. Corrected from `codebook.xlsx` (sheet "Daily"): wishing to do something else / disappointed with performance / other players felt toxic.
4. Pages promised "at least 10 participants per group" but the frustration ranking allowed 8. Minimum raised to 10 everywhere; ranked games went from 59 to 48 and the README numbers were regenerated.
5. 43 uses of `use_container_width`, which Streamlit has deprecated ("will be removed after 2025-12-31"), were removed (full width is now the default); `streamlit>=1.43` is now required.
6. `requirements.txt` listed `shap`, whose `numba` dependency can fail to install on new Python versions and would abort the whole install. SHAP and pytest moved to `requirements-optional.txt`.
7. Skipping `tools/join_parts.py` gave a misleading "file not found, download from GitHub" message; damaged or half-extracted files showed raw Python tracebacks. Both now give a plain message saying what to do.
8. `games.csv` was read with `on_bad_lines="skip"`, which could hide dropped rows. Measured: no rows are lost, so the skip was removed and a damaged file now fails loudly.
9. Dead code removed (an unused variable, an unused `high_threshold` argument, unused imports); `ruff` (rules F, E9, PLE) reports nothing.

Checked and found correct
* Animal Crossing total hours recomputed from the raw Nintendo file without project code: 22,848 h, 368 players, identical to the pipeline.
* Dead by Daylight frustration recomputed from the raw diary: 3.29 raw mean (95 entries, 29 people), consistent with the shrunken 3.17 shown.
* No duplicate rows in the Steam or Nintendo telemetry, no duplicate (participant, date) diary rows, no duplicate (name, platform) in the game metadata, so the play-time join does not double count.
* Telemetry durations are in minutes (max single session 8 h); no unit errors.
* "Frustration falls with age": person-level Spearman -0.17 (p about 1e-7), -0.11 (p = 0.0008) after removing each game's average.
* Old churn project reproduced exactly from a clean copy (Random Forest ROC-AUC 0.772) and Game Lab rebuilt from scratch in about 40 s.
* Prediction page paths (button, CSV upload with valid, missing-column, empty, garbage and negative data) run without crashing.
* Syntax checked under Python 3.11, 3.12 and 3.13; tests ran on 3.13 only.

Still not verified
* Real Streamlit and Plotly were never run, so layout, chart rendering and widget behaviour in a browser are unseen; the stand-in test proves the page code runs, not how it looks.
* pandas 2.x was not available to test (only 3.0.5); the code avoids known pandas 3-only features but this is unproven.
* Windows itself: file paths and encodings were reviewed (explicit UTF-8 for JSON and YAML, pathlib everywhere) but nothing was executed on Windows.
